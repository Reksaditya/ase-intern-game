# Building The Last Gatekeeper

All four desktop/mobile builds are produced by `export_presets.cfg` and written to `bin/`.

| Platform | Output | Architecture | Notes |
| --- | --- | --- | --- |
| Windows | `bin/windows/TheLastGatekeeper.exe` | x86_64 | Single-file build (PCK embedded), unsigned |
| Linux | `bin/linux/TheLastGatekeeper.x86_64` | x86_64 | Single-file build (PCK embedded), executable bit set |
| macOS | `bin/macos/TheLastGatekeeper.zip` | Universal (arm64 + x86_64) | `.app` bundle, built-in ad-hoc signed, not notarized |
| Android | `bin/android/TheLastGatekeeper.apk` | arm64-v8a + armeabi-v7a | Signed release APK, minSdk 24, targetSdk 36 |

## Rebuild everything

```bash
./build_all.sh
```

Set `GODOT=/path/to/godot` to use a specific editor binary. The script:

1. Refreshes the resource import cache.
2. Creates the local development Android keystore if it is missing.
3. Exports each preset in release mode.
4. Writes `bin/SHA256SUMS.txt`.

You can also export a single preset from the Godot editor or CLI:

```bash
godot --headless --path . --export-release "Windows Desktop" bin/windows/TheLastGatekeeper.exe
godot --headless --path . --export-release "Linux"           bin/linux/TheLastGatekeeper.x86_64
godot --headless --path . --export-release "macOS"           bin/macos/TheLastGatekeeper.zip
godot --headless --path . --export-release "Android"         bin/android/TheLastGatekeeper.apk
```

## Requirements

- **Godot 4.7.2** with the matching export templates installed
  (`~/.local/share/godot/export_templates/4.7.2.stable/`).
- **Android:** Android SDK with `build-tools` and `zipalign`/`apksigner`, plus a JDK with
  `keytool`. The SDK/JDK paths are taken from the Godot editor settings
  (`Editor Settings > Export > Android`). Non-Gradle APK export is used, so the Android
  build template is not required.
- **Icons:** generated from `icon.svg` and kept in `assets/export/`
  (`icon.ico`, `icon.icns`, Android launcher icons). They are excluded from the game PCK.

## Important project settings

- `rendering/textures/vram_compression/import_etc2_astc=true` is required when exporting
  for Android or for macOS arm64/universal. Godot refuses those exports otherwise.
- The export presets use `include_filter="*.json"`, which is required because the story
  data in `data/*.json` is loaded with `FileAccess` rather than as a Godot resource.
  Do not remove this filter, or the exported game will have no dialogue/report data.
- `binary_format/embed_pck=true` on Windows and Linux keeps each game in one executable.
- `assets/export/*` is excluded from the PCK because those files are only used as
  platform icons.

## Platform notes

### Windows
The executable is unsigned. Windows SmartScreen may show "Windows protected your PC";
choose **More info > Run anyway**. To distribute publicly, add an Authenticode
certificate via `codesign/enable` and `osslsigncode` in the preset.

The project requests the D3D12 rendering driver on Windows
(`rendering_device/driver.windows="d3d12"`). On a machine where D3D12 is unavailable,
launch with `TheLastGatekeeper.exe --rendering-driver vulkan`.

### Linux
The binary is already executable. If it is copied through a filesystem that drops the
executable bit, run `chmod +x TheLastGatekeeper.x86_64`.

### macOS
The `.app` is **ad-hoc signed** (both arm64 and x86_64 slices) but **not notarized**,
because notarization requires an Apple Developer account and macOS tooling. Gatekeeper
will block it on first launch. Either:

- Right-click the app → **Open** → **Open**, or
- Remove the quarantine flag:

  ```bash
  xattr -dr com.apple.quarantine TheLastGatekeeper.app
  ```

For public distribution, sign with a Developer ID certificate and notarize on macOS
(set `codesign/codesign` to `Xcode codesign`/`rcodesign` and enable notarization).

### Android
The APK is signed with the local development keystore
`keystore/release.keystore` (alias `thelastgatekeeper`, password
`thelastgatekeeper`). This key is generated by `build_all.sh` and is **not** a Play Store
upload key. Back it up if you want to ship updates signed with the same identity.

Install on a connected device with:

```bash
adb install -r bin/android/TheLastGatekeeper.apk
```

For Google Play, create a proper upload key and export an AAB with
**Use Gradle Build** enabled.

## Verifying the builds

```bash
file bin/windows/TheLastGatekeeper.exe bin/linux/TheLastGatekeeper.x86_64
unzip -l bin/macos/TheLastGatekeeper.zip
~/Android/Sdk/build-tools/36.0.0/apksigner verify --print-certs bin/android/TheLastGatekeeper.apk
```

Run the Linux build without a display to smoke-test startup:

```bash
./bin/linux/TheLastGatekeeper.x86_64 --headless --quit-after 120
```

Check embedded data files (should print `33`):

```bash
unzip -l bin/android/TheLastGatekeeper.apk | grep -c 'assets/data/.*\.json'
strings -a bin/linux/TheLastGatekeeper.x86_64 | grep -oE 'data/[A-Za-z0-9_]+\.json' | sort -u | wc -l
```
